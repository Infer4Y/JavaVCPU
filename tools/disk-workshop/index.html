Create a short tune

One MIDI note number and duration per line. Durations are 33 ms frames. Up to 7,649 notes.

Stop the VM before replacing its disk. Download the updated image, rename it to storage.img in your JavaVCPU folder, then start the VM. In DOS use VIEW FILE.TXT, IMAGE FILE.IMG, PLAY FILE.JMT, or RUN FILE.JVS. Use uppercase JVS keywords; CODEHELP lists the language. Nothing is uploaded to a server.

MIDI: Standard MIDI format 0/1, PPQN timing, eight output voices and up to 15,299 events. When notes overlap beyond eight voices, new notes replace the oldest sounding notes. Instruments use synthesized triangle waves; percussion uses noise. Oversized files are rejected rather than silently truncated.
